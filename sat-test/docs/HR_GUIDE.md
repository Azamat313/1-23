# Тест SAT: инструкция для HR и проверяющего

## Как это работает

1. HR отправляет кандидату ссылку на сайт теста.
2. Кандидат заполняет анкету и 30 минут решает 8 заданий, к каждому пишет объяснение.
3. Через минуту после отправки в таблице появляется строка с баллами, а HR получает уведомление.
4. Проверяющий оценивает объяснения, таблица сама считает итог.
5. HR приглашает на интервью кандидатов с итогом «Прошёл».

Строка кандидата появляется в «Результатах» уже при старте теста со статусом «В процессе» —
видно, кто проходит тест прямо сейчас. Брошенные попытки закрываются автоматически не позже чем
через 15 минут после окончания времени (статус «Не завершён», оценка по автосохранению).

## Листы таблицы

| Лист | Для чего |
| --- | --- |
| **Результаты** | Одна строка на попытку: контакты, баллы, статусы, флаги |
| **Ответы** | 8 строк на попытку: условие, ответ, ключ, объяснение, оценка |
| **Резерв** | Кандидаты со статусом «Резерв» — собирается сам, руками не править |
| **Вопросы**, **Настройки** | Для администратора |
| Попытки, Лог | Скрытые служебные листы, не трогать |

Серые автоколонки заполняет сервер — при попытке правки таблица предупредит. Свободно
редактируются колонки с жёлтым фоном: «Проверил», «Комментарий», «Разрешить пересдачу»,
а в «Ответах» — «Оценка объяснения» и «Комментарий проверяющего».
Сортировать и фильтровать можно как угодно: листы связаны по ID попытки, а не по номерам строк.

## Как читать «Результаты»

- **Math, R&W, Итого** — число верных ответов (по 0–4, итого 0–8).
- **Автостатус** (считает сервер по баллам):
  «Прошёл» — итого ≥ 7 и каждая секция ≥ 3;
  «Резерв: Math» / «Резерв: R&W» — одна секция ≥ 3, другая ≤ 2;
  «Не прошёл» — остальное.
- **Итог теста** — главная колонка, считается сама:

| Итог | Цвет | Что делать |
| --- | --- | --- |
| В процессе | серый | Ждать |
| Не прошёл: баллы | красный | Отказ |
| Резерв: Math / Резерв: R&W | синий | Не отклонять окончательно, кандидат в листе «Резерв» |
| Проверить объяснения | жёлтый | Проверяющему — оценить объяснения |
| Прошёл | зелёный | Пригласить на интервью |
| На усмотрение | жёлтый | Решает Тилек |
| Не прошёл: объяснения | красный | Отказ |

- **Баллы vs требования** — сверка баллов SAT/IELTS из анкеты с требованиями вакансии.
- **Флаги** — подсказка, на что посмотреть; статус они не меняют. Жёлтым подсвечено:
  уходы со страницы ≥ 3 раз или ≥ 60 с, вставка ≥ 100 символов, копирование условия,
  отправка с опозданием, повторная попытка. Подлинность объяснений проверяется на интервью.
- **Ответы → «Открыть»** — переход к 8 строкам кандидата в листе «Ответы».

## Как оценивать объяснения (проверяющий)

1. В «Результатах» отфильтруйте «Итог теста» = «Проверить объяснения».
2. Нажмите «Открыть» в строке кандидата.
3. В каждой из 8 строк выберите «Оценку объяснения» из списка:

| Оценка | Что значит |
| --- | --- |
| 5 | Верно, пошагово, простыми словами, как для ученика; есть стратегия или типичная ошибка |
| 4 | Верно и понятно, мелкие недочёты |
| 3 | В целом верно, но слишком кратко или сумбурно: ученик поймёт с трудом |
| 2 | Ошибки в рассуждении или объяснение не совпадает с ответом |
| 1 | Объяснения нет, бессмысленный текст или явно скопировано |

4. В «Результатах» заполните «Проверил». Когда оценены все 8 объяснений, «Итог теста» пересчитается:
   обе средние (Math и R&W) ≥ 4,0 — «Прошёл»; меньшая из средних ≥ 3,0 — «На усмотрение»; иначе — «Не прошёл: объяснения».

Оценивать нужно только кандидатов с автостатусом «Прошёл».

## Частые действия

**Закрыть или открыть приём.** «Настройки» → «Приём открыт» → «Нет» / «Да». Кандидаты увидят
«Приём ответов сейчас закрыт»; уже начатые попытки можно доучить.

**Разрешить пересдачу.** Поставьте галочку «Разрешить пересдачу» в строке кандидата.
Он сможет пройти тест ещё раз с тем же телефоном и email; появится новая строка с флагом
«Повторная попытка», старая останется. Разрешение действует на одну попытку.

**Кандидат пишет «Вы уже проходили тест», но это ошибка.** Найдите его по телефону или email
в «Результатах» и разрешите пересдачу.

**Сменить вопрос или ключ.** Лист «Вопросы»: измените условие, варианты A–D и «Ключ»
(для числа — число, например `-11`; для уравнения — `m;b`, например `3;-1`; для выбора — буква A–D).
Чтобы заменить вопрос, поставьте старому «Активен» = «нет», а новому на той же позиции — «да».
Затем меню **SAT-тест → Проверить лист «Вопросы»**. Если есть ошибка, тест не запустится,
пока её не исправить. Изменения получат новые попытки; начатые проверяются по старым вопросам.

**Сменить пороги, длительность, тексты.** Лист «Настройки», колонка «Значение».

**Не пришло уведомление.** Проверьте «Email для уведомлений» в «Настройках», затем
меню **SAT-тест → Отправить тестовое уведомление**. Ошибки записываются в скрытый лист «Лог»
(правый клик по ярлыкам листов → «Показать»). Результат в таблице при этом не теряется.

**Удалить данные кандидата по его запросу.** Удалите его строку в «Результатах», 8 строк в «Ответах»
и строку в скрытом листе «Попытки» (поиск по ID попытки, например SAT-0017).

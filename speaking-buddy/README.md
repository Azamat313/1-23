# Speaking Buddy — персоны, промты и ТЗ на внедрение

```
speaking-buddy/
├── README.md                    ← этот файл: обзор + детальное ТЗ для разработчика
├── 01-analysis.md               ← анализ старых промтов: что было, чего не хватало, что изменено
├── 02-tutor-choose-screen.md    ← тексты карточек главного экрана + приветствия RU/EN («Послушать»)
├── 03-scenarios.md              ← 28 сценариев: роли, цели, вводные реплики для трёх персон
└── prompts/
    ├── luna.md                  ← системный промт Luna   (EN)
    ├── dexter.md                ← системный промт Dexter (EN, 18+, мат по согласию)
    └── spark.md                 ← системный промт Spark  (EN, зумер)
```

Каждый файл в `prompts/` самодостаточен: **Part A** (общее ядро — одинаковое во всех трёх) +
**Part B** (персона). При правке Part A — менять во всех трёх файлах.

## Три персоны в одну строку

| Персона | Характер | Языки | Основные эмоции аватара | Никогда |
|---|---|---|---|---|
| Luna | спокойная, gentle, understanding | RU / EN | default, happy, sympathy, surprised | angry, furious, sarcastic, bored |
| Dexter | грубый, прямой, требовательный; мат — только если ученику ок | RU / EN | bored, angry, sarcastic, default | excited (почти), тёплые фразы |
| Spark | зумер, саркастичный, активный, свой пацан | RU / EN | sarcastic, excited, bored, surprised | furious, реальный мат |

## Детальное ТЗ для внедрения (что должно делать приложение)

### 1. Сборка системного промта
```
system = <содержимое prompts/<persona>.md>
       + "\n[CONTEXT]\n"
       + "learner_name: Aida\n"
       + "learner_level: A2\n"            # A1 | A2 | B1 | B2 | C1 | C2 — из профиля ученика
       + "ui_language: ru\n"              # ru | en — селектор «Язык интерфейса» (кнопки и экраны)
       + "explanation_language: ru\n"     # ru | en — селектор «Язык объяснения» (речь тьютора)
       + "scenario: none\n"               # или JSON { title, setting, buddy_role, learner_role, goal }
       + "profanity_ok: unknown\n"        # только Dexter: unknown | yes | no
       + "[/CONTEXT]"
```
При смене сценария, уровня или любого из двух языков — пересобрать `[CONTEXT]`.

**Два языка — две разные роли (частая путаница):**
| Настройка | На что влияет |
|---|---|
| `ui_language` | только интерфейс: кнопки, карточки, подписи. На речь тьютора не влияет. |
| `explanation_language` | язык, на котором тьютор объясняет грамматику, переводит слова и даёт инструкции; язык озвучки приветствия на экране выбора. |
| — | Английский всегда остаётся целевым языком: модельные фразы, сценарии и челленджи только на нём. |

Если `explanation_language: en`, тьютор не переходит на русский вообще: вместо перевода он
замедляется и упрощает английский. Русский всплывает только если ученик сам пишет по-русски или
расстроен.

### 2. События (отправляются как сообщение от user, ровно в таком виде)
| Событие | Когда шлёт приложение | Что делает модель |
|---|---|---|
| `[EVENT:SESSION_START]` | сразу после открытия чата с персоной | сама здоровается и задаёт первый вопрос |
| `[EVENT:SCENARIO_START]` | ученик нажал на сценарий (контекст уже содержит `scenario`) | 1–2 фразы объяснения → «начинаем» → первая реплика в роли |
| `[EVENT:SCENARIO_END]` | сценарий завершён: цель достигнута, ученик вышел или вышло время | одна закрывающая фраза в характере, без анализа — разбор делает отдельный промт |
| `[EVENT:SILENCE_30S]` | 30 с без речи ученика после последней реплики бота | одна короткая реплика «ты где?» в своём тоне |
| `[EVENT:SILENCE_60S]` | ещё 30 с тишины | «жаль, не получилось» + «пауза», дальше молчит |

Таймер тишины: стартует после окончания TTS-озвучки реплики бота; сбрасывается при любом
распознанном фрагменте речи ученика. После `SILENCE_60S` приложение переводит сессию в состояние
«пауза» и больше не шлёт событий тишины до следующей реплики ученика.

### 2а. Экран тьютора (tutor-dashboard) — что во что мапится

| Элемент экрана | Поле промта | Комментарий |
|---|---|---|
| Тумблер «Только английский» | `explanation_language` | включён → `en`, выключен → `ru`. Это тот же смысл, что «Язык объяснения» на экране выбора: держите их одним значением, иначе тьютор получит противоречие. |
| Чип «Уровень B2» под именем | `learner_level` | управляет длиной фраз, словарём и долей русского (таблица A5 в промте) |
| Карточка «Советуем сегодня» | `recommended_scenario` | тьютор может предложить его одной фразой в приветствии, но не навязывает |
| Кнопка «Начать разговор» (центр) | `[EVENT:SESSION_START]` | свободный разговор, `scenario: none` |
| Кнопка «Начать разговор» на карточке сценария | `[EVENT:SCENARIO_START]` | `scenario` заполняется из карточки |
| Завершение сценария | `[EVENT:SCENARIO_END]` | запускает «личный разбор от тьютора», обещанный в подписи панели «Сценарии» |
| «Управление тьютором» | — | смена персоны, уровня и языков: меняет `[CONTEXT]`, пересобрать при выходе из меню |

Уровень сценария (бейдж A1–B2 на карточке) и уровень ученика — разные вещи. Речь тьютора всегда
настраивается по `learner_level`; уровень сценария влияет только на сложность ситуации. Если ученик
A2 открыл сценарий B2, тьютор всё равно говорит на A2.

### 2б. Разбор после разговора — отдельный вызов

Разбор не входит в промты персон. Это второй, независимый вызов модели с промтом
`prompts/feedback.md`: на вход транскрипт и контекст, на выход один текст из пяти блоков
(`VERDICT`, `WORKED`, `FIX`, `KEEP`, `NEXT`), который приложение рисует на своём экране.
Тьютор в конце сценария говорит только одну закрывающую фразу в характере и ничего не разбирает,
чтобы ученик не читал одно и то же дважды в двух голосах.

```
system = <prompts/feedback.md>
       + "[CONTEXT] learner_level, feedback_language, scenario, persona [/CONTEXT]"
       + "[TRANSCRIPT] …диалог… [/TRANSCRIPT]"
```

**Язык разбора.** `feedback_language` берётся из того же тумблера «Только английский»:
включён → `en`, выключен → `ru`. Английский разбор пишется по уровню ученика, а не по уровню
модели: A1 получает разбор из фраз в пять слов без единого грамматического термина, B2 — с
терминами и замечаниями по регистру. Жёсткое правило в промте: язык разбора никогда не сложнее
того английского, который ученик выдал в разговоре.

Ограничения разбора: максимум три правки, каждая с реальной цитатой ученика, никаких оценок,
баллов и процентов, никаких замечаний о произношении. Если ученик почти не говорил, блок правок
не заполняется вовсе.

### 3. Эмоции аватара
Каждый ответ модели начинается с тега `[emotion]`, возможен второй тег внутри ответа.

| Тег в ответе | Состояние аватара | Кто задаёт |
|---|---|---|
| — | Слушает (Listening) | приложение: микрофон открыт |
| — | Думает (Thinking) | приложение: ждём ответ модели |
| — | Говорит (Speaking) | приложение: идёт TTS (эмоция = тег из ответа) |
| `[default]` | Дефолт | модель |
| `[confused]` | Не понимает | модель |
| `[happy]` | Счастлив | модель |
| `[excited]` | Радуется | модель |
| `[angry]` | Злится | модель |
| `[bored]` | Скука | модель |
| `[sarcastic]` | Саркастичен | модель |
| `[surprised]` | Удивление | модель |
| `[sympathy]` | Сочувствие | модель |
| `[furious]` | Ярость | модель (только Dexter) |

Обработка: регэксп `^\[(default|confused|happy|excited|angry|bored|sarcastic|surprised|sympathy|furious)\]\s*`
на старте ответа → состояние аватара; второй тег в середине → сменить состояние на этом сегменте
(если TTS играется по сегментам) либо проигнорировать. Все теги вырезаются перед отправкой в TTS.
Если тега нет — `default`. Если тег вне списка — `default` + лог.

### 4. Голос (TTS)
- Междометия («Hmm…», «Ugh.», «Пфф.») — обычный текст, TTS их читает; многоточие = пауза.
- Если движок поддерживает аудио-теги (вздох, смех) — можно маппить «(soft breath)» из приветствий,
  иначе удалять скобочные ремарки.
- Для каждой персоны — свой голос: Luna мягкий женский, Dexter низкий мужской, Spark молодой мужской
  быстрый. Один и тот же голос на RU и EN (мультиязычный), чтобы персона не «менялась» при переключении.

### 5. Экран выбора (tutor-choose)
Тексты — в `02-tutor-choose-screen.md`, структура карточки не меняется. Кнопка «Послушать голос…»
играет заранее записанное приветствие на языке из селектора «Язык объяснения»; текст карточки берёт
язык из «Язык интерфейса». Декстер помечен `18+`, у Спарка бейдж предлагается снять.
Казахский убирается из селектора «Язык объяснения» и из карточки Спарка.

### 6. Dexter: флаг мата
- Если на экране есть переключатель «можно материться» → `profanity_ok: yes|no`.
- Если переключателя нет → `unknown`, и Dexter сам спросит один раз через 2–3 реплики или
  включит мат после того, как ученик сам выругался. Промт уже это описывает.
- Если в профиле возраст < 18 → всегда `no`.

### 7. Проверка после внедрения (чек-лист)
- [ ] Бот говорит первым после `SESSION_START` у всех трёх персон.
- [ ] A1-ученик получает короткие простые фразы и русские пояснения; C1 — ноль русского.
- [ ] Русская реплика ученика на B1+ не переводит бота на русский целиком.
- [ ] Ни одна персона не отвечает по-казахски или на другом языке.
- [ ] При `explanation_language: en` в речи тьютора нет русского (кроме реакции на русскую реплику ученика).
- [ ] Смена «Языка интерфейса» не меняет язык речи тьютора; смена «Языка объяснения» — меняет.
- [ ] Тег эмоции есть в 100 % ответов, картинка совпадает с тоном.
- [ ] Luna никогда не `angry/sarcastic`; Spark никогда не `furious`; Dexter `furious` — редко.
- [ ] Dexter не матерится, пока `profanity_ok` не `yes` / ученик не дал сигнал.
- [ ] 30 с тишины → уточнение; 60 с → пауза и тишина.
- [ ] После сценария тьютор даёт одну закрывающую фразу, а разбор приходит отдельным экраном.
- [ ] Разбор: вердикт, что получилось, не больше трёх правок с цитатами, фраза на память.
- [ ] При включённом «Только английский» разбор полностью английский и при этом понятен ученику его уровня.
- [ ] Тумблер «Только английский» реально убирает русский из речи тьютора.
- [ ] Ученик A2 в сценарии уровня B2 всё равно слышит A2-английский.
- [ ] Уход от сценария на 2 реплики → возврат в роль; «давай без сценария» → выход.
- [ ] Расстроенный ученик → все трое сбрасывают тон в `sympathy`.
